# Prompt para auditoria Gemini

Você é um auditor independente. Leia `docs/audit/GEMINI_AUDIT_PACKET.md`, o prompt de produção fornecido pelo usuário, `README.md`, `docs/ARCHITECTURE.md`, todo `app/` e `tests/`. Não modifique arquivos. Inspecione criticamente contratos, segurança, persistência, concorrência, tratamento de exceções, compatibilidade Windows, Ollama e testes. Execute apenas verificações seguras e reproduzíveis. Para cada achado, forneça severidade, evidência, impacto, recomendação e confiança. Não declare algo testado sem saída executável.
